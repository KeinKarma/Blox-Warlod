# Blox Warlord - Roblox Game 🐉

Ein Monster Warlord-ähnliches Spiel für Roblox mit vollständiger GUI und Quest-System!

## 🎮 Features

✅ **Ressourcen-System:**
- 💰 Gold (für Monster und Items kaufen)
- 💎 Diamanten (Premium Währung)
- ⚡ Energie (für Quests)
- ❤️ HP (Gesundheit)
- 🛡️ Ausdauer (für World Boss Kämpfe)

✅ **Level & Skill System:**
- Experience Points sammeln durch Quests
- Level aufsteigen
- Skill Punkte bekommen pro Level
- Skill Punkte auf Ausdauer, Energie oder HP verteilen

✅ **Menüs:**
- Hauptmenü (Start-Screen)
- Monster-Sammlung
- Shop
- World Boss Kämpfe
- Daily Raid
- Spieler-Profil
- Inventar

## 📋 Installation

Folge der detaillierten Anleitung in `INSTALLATION.md`

## 🎯 Schnellstart

1. Lese `INSTALLATION.md`
2. Erstelle die GUI-Struktur in Roblox Studio
3. Kopiere die Lua-Scripts
4. Teste mit Play-Button!

## 🎮 Test-Befehle

Während dem Spielen:
- **Q** = Quest machen (1 Energie)
- **W** = World Boss angreifen (10 Ausdauer)
- **E** = Ausdauer Skill (+5 max Ausdauer)
- **R** = Energie Skill (+5 max Energie)
- **T** = HP Skill (+50 max HP)
